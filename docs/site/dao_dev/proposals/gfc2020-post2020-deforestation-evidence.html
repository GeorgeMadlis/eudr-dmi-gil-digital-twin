Add dynamically versioned GFC2020-based post-2020 deforestation evidence layer to the EUDR Digital Twin

Proposal ID: SCP-2026-001-gfc2020-post2020-deforestation-evidence | Status: DRAFT | Created: 2026-07-04

Implementation Intent

Add a deterministic, inspectable evidence layer that intersects post-2020 disturbance datasets with a GFC2020 2020 forest baseline, records dataset versions and temporal coverage, and separates agricultural-conversion evidence from forest-disturbance evidence.

Non-decision rule: report outputs must classify evidence state only; they must not assert EUDR compliance or non-compliance.

DAO (Developers) Tasks

  1. Add GFC2020 baseline metrics to AOI evidence bundles.
  2. Add Hansen post-2020 loss metrics inside the GFC2020 forest mask.
  3. Add optional JRC TMF deforestation/degradation metrics where geographically applicable.
  4. Add optional RADD confirmed and low-confidence alert metrics where geographically applicable.
  5. Add optional Sentinel-1/2 local confirmation indices.
  6. Add agricultural-conversion evidence fields, initially nullable.
  7. Add deterministic decision-rule outputs that classify evidence state without asserting legal compliance.
  8. Add a dataset registry that records dataset asset IDs, versions, temporal coverage, latest available year, and update policy.
  9. Implement --end-year auto so the system resolves the latest available complete evidence year dynamically.
  10. Implement explicit end-year pinning for reproducibility.
  11. Update report templates, JSON schemas, documentation, and tests.
  12. Add conflict-register support for disagreement among evidence layers.
  13. Add acceptance tests using public example AOIs only.

Acceptance Gates

  1. Reports expose GFC2020 baseline forest area and post-2020 disturbance metrics.
  2. Disturbance is computed only for years 2021 and later and only inside the 2020 forest baseline.
  3. Automatic end-year resolution records requested, resolved, latest-available, and used-through years.
  4. Explicit end-year pinning reproduces the same output for the same inputs.
  5. Agricultural-conversion evidence remains separate and nullable.
  6. Dataset disagreement is preserved in a conflict register.
  7. Missing conversion evidence and temporal-coverage gaps are displayed as evidence gaps or warnings.
  8. Only public example AOIs are used in acceptance tests and public bundles.
  9. The output is deterministic, inspectable, and suitable for static publication in the Digital Twin portal.
